# 边缘 AI 案例库

案例库用于说明完整项目如何使用 GITS。每个案例独立成目录，包含操作说明、可复制的 manifest、结果检查方法和待补材料。

| 场景 | 入口 | 当前状态 |
| --- | --- | --- |
| 工业瑕疵检测 | [案例说明](工业瑕疵检测/README.md) | 已有 YOLO 单图工程和环境清单；待真实缺陷模型、测试数据和业务验收 |
| 安全帽识别 | [案例说明](安全帽识别/README.md) | 已有 YOLO 单图工程和环境清单；待真实模型、人员关联与告警模块 |
| VisionEngine 边缘部署 | [案例说明](VisionEngine边缘部署/README.md) | 依据现有使用记录提供包同步清单；待完整依赖、启动配置和设备验收 |

以上三个方向不是三个“已验证的完整客户解决方案”。现有资料没有包含可公开的真实模型、设备数据和完整业务配置，不能以虚构结果补足。完成下列验收后才能将案例标为已验证。

## 完整案例需要什么

| 材料 | 要求 |
| --- | --- |
| 业务目标 | 输入、输出、适用设备和使用边界明确 |
| 工程 | 能构建的源码或实际可获取的发行包 |
| 环境 | manifest、编译器、架构、SDK 与 GITS 版本 |
| 模型和数据 | 合法获取方式、模型格式、类别和测试输入 |
| 操作 | 实际可执行的安装、构建、启动、停止和复测步骤 |
| 结果 | 一组真实输入输出、脱敏日志及设备验收记录 |
| 故障处理 | 常见故障、恢复或回退到旧版本的方法 |

## 使用顺序

先完成 [快速入门](../01-快速入门.md) 的安装和配置，再选择对应案例。需要上传新业务模型包或维护依赖时，查阅 [进阶教程](../02-进阶教程.md)。

性能数据须记录实际硬件、模型、输入尺寸、样本和统计方法；没有实测时不填写 FPS、准确率或延迟数值。
