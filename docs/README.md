# GITS 文档

GITS 的管理端负责发布和维护环境包，CLI 负责下载环境包、准备运行目录和管理 CMake 工程。文档按“三类使用文档 + 一个案例库”组织。

## 选择阅读入口

| 类型 | 入口 | 适合谁 | 读完能做什么 |
| --- | --- | --- | --- |
| 1. 快速入门 | [5 分钟快速入门](01-快速入门.md) | 第一次使用的人 | 安装配置、同步依赖、构建并尝试运行 YOLO 示例 |
| 2. 进阶教程 | [进阶教程](02-进阶教程.md) | 开发和维护人员 | 发布包、开发算子、管理编译器和固定依赖版本 |
| 3. API 参考 | [命令与配置参考](03-命令与配置参考.md) | 日常使用者和自动化开发者 | 查询命令、参数、配置、manifest 和常见问题 |
| +1. 案例库 | [案例库](案例库/README.md) | 项目实施和交付人员 | 按业务场景准备工程、运行输入并核对结果 |

第一次使用按“快速入门 → 进阶教程 → 对应案例”阅读；命令与配置参考按需查询，不必从头读完。

## 配套资料

[管理端使用手册](管理端使用手册.md) 单独说明页面操作。上传发布等跨端流程已经放入进阶教程，不需要先读完两套手册才能开始。

文档依据是用户提供的《GITS V2.0 用户文档（Windows）》PDF、《Gits 管理端使用指南》Word，以及当前 CLI 源码。当前以 Windows 为主；Linux 产品部署暂不展开。V2.0 是功能文档代际，实际程序版本以 `gis version` 为准。

## 当前可用程度

- 快速入门提供现有 YOLO C++ 工程、环境清单及构建运行步骤；模型、图片和兼容 SDK 需自行准备。前期只完成 C++ 语法检查，真实推理仍需目标设备验收。
- 进阶教程包含实际命令和管理端发布步骤。交叉编译目前说明工具链接入方式，当前仓库不含可直接运行的跨平台工具链。
- 案例库包含三个独立方案及可复制的环境清单。缺少模型、业务配置或真实验收数据的地方均列出待补材料，尚不作为三个“已验证的完整解决方案”发布。
