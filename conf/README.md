# 模拟仓库的配置

此目录使用公开示例值，未包含本地正式环境的服务器地址、账号密码或管理密码。

Codespaces 使用 `playground/bootstrap.py` 创建的独立配置和本地包适配器，无需修改这里的连接信息。

真实部署应按主文档配置自己的连接信息，并设置 `GITS_CONFIG_PASSWORD`。配置生成器支持 `GITS_LEAN_REMOTE_IP`、`GITS_LEAN_REMOTE_PORT`、`GITS_LEAN_REMOTE_USER`、`GITS_LEAN_REMOTE_PASSWORD` 和 `GITS_LEAN_REMOTE_PATH` 环境变量。请在自己的部署环境中保管这些值。
